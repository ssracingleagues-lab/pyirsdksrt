ℹ️ OBS Setup Instructions

  1. Open OBS Studio
  2. Add a new Browser Source
  3. Set the URL to: http://localhost:5000/overlay
  4. Set Width: 1920 and Height: 1080
  5. Check "Shutdown source when not visible"
  6. Check "Refresh browser when scene becomes active"
  7. Click OK
